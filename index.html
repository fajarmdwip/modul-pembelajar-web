Pertemuan 1: Pengantar Web

Pengertian dan Klasifikasi Website

Website adalah sekumpulan halaman digital berisi teks, media visual, dan interaktif yang disimpan di web server dan dapat diakses publik melalui protokol HTTP/HTTPS. Website dibagi menjadi tiga klasifikasi utama:

  • Web Statis: Kontennya jarang berubah. Setiap perubahan informasi harus dilakukan dengan merombak script HTML secara manual (misal: landing page sederhana).
  • Web Dinamis: Dirancang dengan konten yang sering berubah secara otomatis, biasanya mengambil data dari database dan memiliki panel pengelolaan data khusus (misal: portal berita, e-commerce).
  • Web Interaktif: Memungkinkan terjadinya komunikasi dua arah antar pengguna (misal: forum online, jejaring sosial, portal dengan chat & komentar).

Perangkat Kerja & Pemrograman Web

Pemrograman web ditulis menggunakan bahasa scripting (HTML, CSS, JS di client-side; PHP, Java, Python di server-side). Untuk menulis kodenya dibutuhkan text editor, seperti:

  • Notepad++: Editor teks gratis yang sangat ringan untuk sistem operasi Windows.
  • VS Code: Editor modern besutan Microsoft yang sangat kaya akan ekstensi pembantu.
  • Sublime Text: Editor cepat dengan antarmuka minimalis dan fitur pencarian canggih.
Pertemuan 2: Tag & Heading HTML

Struktur Dasar HTML & Elemen Konten

Dokumen HTML disusun berdasarkan elemen-elemen tag pembuka dan penutup untuk memetakan konten di dalam browser web.

HTML Source Code 
<html>
<head>
  <title>Struktur Dasar Pertama</title>
</head>
<body bgcolor="#FB7DA8" text="#000000">
  Halo Dunia!<br>
  Ini script pertamaku.<br>

Fungsi & Penjelasan Kode

  • <body>: Berisi konten visual utama yang tampil langsung di browser.
  • bgcolor & text: Atribut body untuk mengatur warna latar halaman dan warna teks dasar.
  • <br>: Line Break, digunakan untuk berpindah ke baris baru.
  • <h1> s/d <h6>: Membuat Heading (judul) dari yang terbesar (H1) ke terkecil (H6).
  • align="center": Atribut pemosisian teks agar berada di tengah.
  • <marquee>: Elemen tag bawaan untuk membuat teks berjalan secara otomatis.

function hitungIPK() {

Pertemuan 7: Perulangan PHP

Perulangan Terstruktur dengan Statemen FOR

Struktur perulangan digunakan untuk mengulang jalannya blok kode secara berulang sesuai batas iterasi numeris.

PHP For Loop Code 
<?php
  for ($i = 1; $i <= 5; $i++) {
    echo "Loop Ke: " . $i . "<br>";
  }
?>

Fungsi & Penjelasan Kode

  • for (...): Konstruksi loop utama yang menerima deklarasi awal, syarat batas, dan ekspresi langkah.
  • $i = 1: Inisialisasi awal variabel pencatat putaran (counter) bernilai 1.
  • $i <= 5: Persyaratan logika batas perulangan (loop terus berjalan selama bernilai TRUE).
  • $i++ (Increment): Operasi penambahan nilai counter sebanyak 1 setiap putaran selesai.

Pertemuan 10: CSS & Responsive Layout

Penyusunan Grid Fleksibel & Media Queries

Media Queries digunakan untuk merubah struktur sekat elemen web secara dinamis menyesuaikan lebar layar viewport browser.

CSS Responsive Code 
/* Struktur Grid Flex */
.wrapper {
  display: flex;
  flex-wrap: wrap;
}

/* Penyesuaian Tablet/Mobile */
@media screen and (max-width: 768px) {
  .col-left, .col-main {

  • max-width: 768px: Mengatur batasan lebar resolusi layar maksimal untuk eksekusi kode CSS responsif.

Arsitektur MVC & Server Apache Tomcat

Pertemuan 21: Servlet API

Daur Hidup & Fungsional Respons Servlet Java

Servlet bertindak sebagai API pemroses request dinamis di server Java yang memiliki tahapan siklus kerja tertentu.

Servlet Java Concept Structure 
public class MyServlet extends HttpServlet {
  // Daur Hidup Servlet
  public void init() { ... }
  protected void service(req, res) { ... }
  public void destroy() { ... }
}

Fungsi & Penjelasan Kode

  • init(): Dipanggil satu kali oleh Container saat instansiasi servlet pertama kali dibuat.
  • service(): Metode inti penentu rute permintaan yang membagi eksekusi ke doGet atau doPost.
  • destroy(): Dipanggil sebelum Servlet instance dimusnahkan/dihapus dari alokasi memory server.
  • addCookie(Cookie c): Menyisipkan data kuki pelacak ke dalam header respon web klien.
  • encodeRedirectURL(String url): Melakukan enkoding url referensi tujuan pengalihan link web.
  • sendError(int sc): Mengirimkan balik sinyal kode kesalahan status respon HTTP (seperti 404, 500).
